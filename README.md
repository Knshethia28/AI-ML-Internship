## 🏆 Featured Project: ShopEase AI Customer Support

Developed across Days 18–24 and finalized in Days 27–30, **ShopEase** is an end-to-end autonomous customer support system:
- **Orchestration:** LangGraph multi-agent state graph (Coordinator, Researcher, Writer, Critic).
- **Backend API:** FastAPI with asynchronous endpoints, health checks, and session memory.
- **Data & Tools:** Local knowledge base search, product catalog query engine, and escalation tracker.
- **Frontend:** Interactive web chat interface (`HTML/CSS/JS`) supporting multi-turn conversations.
- **Engineering Quality:** Automated test suite (`pytest`), structured logging, and Docker deployment.
