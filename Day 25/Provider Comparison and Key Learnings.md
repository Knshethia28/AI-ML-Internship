## Key learning points

### Production AI
- Production AI means deploying and operating AI applications for real users, not just building a working prototype.
- Scalability is the ability to handle increasing workloads; latency is the time taken to respond; reliability is consistent operation.
- Monitoring tracks performance, errors, usage and costs after deployment.
- MLOps applies software engineering and operational practices across the machine-learning lifecycle.

### Token usage
- Tokens are the units of text processed by an AI model; a token may be a whole word, part of a word or punctuation.
- Input tokens include the prompt and supplied context; output tokens are generated by the model.
- Many APIs charge separately for input and output tokens, so token consumption directly affects operating cost.
- A context window limits how much information a model can process in one interaction.

### Cost optimization
- Model selection should match the complexity of the task; not every request needs the most expensive model.
- Prompt optimization reduces unnecessary input tokens.
- Caching can avoid repeated API calls for reusable questions and results.
- Output limits and supported batch-processing options can help control usage and expenses.
- Cost should be evaluated alongside speed, accuracy and suitability rather than in isolation.

### Provider comparison
- Provider-level speed figures and independently measured benchmark results are not automatically comparable.
- Accuracy index scores are benchmark measures, not percentages of answers that are correct.
- Groq is an inference provider hosting models developed by other organizations; its inference speed should be distinguished from the underlying model's intelligence.
- There is no universally best provider: the appropriate choice depends on cost, latency, accuracy, workload and deployment requirements.
