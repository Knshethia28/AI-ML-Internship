# Day 6 - Data Visualization with Matplotlib

This folder contains the data visualization practice completed as part of **Day 6** of the **Linkific AI/ML Internship**, focusing on graphical exploratory analysis, statistical charting, and visual storytelling using **Matplotlib** and **Pandas**.

---

## 📂 Files Included

### 1. `student_data.csv`
The dataset containing student academic performance and activity metrics:
- **Attributes**: `Student_ID`, `Name`, `Department`, `Age`, `Attendance`, `Python_Marks`, `ML_Marks`, `Projects`.

### 2. `data_visualisation.ipynb`
An interactive Jupyter Notebook covering essential visualization types:
1. **Data Ingestion & Missing Value Check**: Loading and inspecting data hygiene.
2. **Bar Chart**: Comparing average Python and Machine Learning marks between `CSE` and `AIML` departments.
3. **Line Chart**: Tracking individual performance trends across Python and ML marks.
4. **Histogram**: Visualizing the frequency distribution of student attendance.
5. **Pie Chart**: Showing the proportion of students based on completed project counts.
6. **Scatter Plot**: Analyzing the correlation and relationship between Python and Machine Learning scores.
7. **Key Insights & Observations**: Synthesizing trends, department comparisons, and score patterns.

---

## 🚀 How to Run

Ensure the required visualization packages and Jupyter are installed:

```bash
pip install pandas matplotlib jupyter
```

Launch the notebook:

```bash
jupyter notebook data_visualisation.ipynb
```
*(Or open directly in VS Code using the Jupyter extension)*
