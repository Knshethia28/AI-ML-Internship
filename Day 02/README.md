# Day 2 - Python Fundamentals & Mini Projects

This folder contains the Python practice exercises and mini projects completed as part of **Day 2** of the **Linkific AI/ML Internship**.

---

## 📂 Files Included

### 1. `python_practice.py`
A practice script covering Python programming essentials:
- **Variables & Data Types**: Strings, integers, floats, booleans.
- **Conditional Statements**: `if`, `elif`, `else`.
- **Loops & Iteration**: `for` loops with `range()`, iterating through lists, `while` loops.
- **Loop Control**: `break` and `continue`.
- **Functions**: Function definitions, parameters, and return values.

### 2. `simple_calculator.py`
A menu-driven command-line calculator that performs basic arithmetic operations:
- **Operations**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`).
- **Features**: Robust numerical input validation and division-by-zero protection.

### 3. `student_grade_calculator.py`
A student grading application that calculates marks and prints an academic report card:
- **Features**:
  - Dynamic subject count and marks entry validation (`0 - 100`).
  - Total marks and percentage calculation.
  - Grade and performance status determination (`A+` to `F`).
  - Formatted terminal report card.

---

## 🚀 How to Run

Run any of the scripts using Python from the command line:

```bash
# Run python practice script
python python_practice.py

# Run simple calculator
python simple_calculator.py

# Run student grade calculator
python student_grade_calculator.py
```
