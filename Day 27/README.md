# Day 27 – ShopEase AI Project Planning & Sprint Management

## Overview

Today's task focused on planning a complete AI project and organizing its development using Agile and Scrum principles.

The selected project is ShopEase, a multi-agent AI-powered e-commerce customer support assistant. The planning exercise builds on the existing prototype and identifies the requirements, architecture, development tasks and future improvements needed to extend it.

## Project Selected

**ShopEase – AI-Powered Multi-Agent E-Commerce Customer Support Assistant**

A customer support application that processes e-commerce queries through a coordinated multi-agent workflow, retrieves relevant information from a knowledge base, analyses the retrieved content and generates appropriate responses.

The planned improvements include RAG-based retrieval, external LLM integration and basic order-status lookup.

- **Domain:** Artificial Intelligence / E-Commerce
- **Complexity:** Moderate
- **Planned Duration:** 8 Weeks
- **Sprint Structure:** 4 Sprints (2 Weeks Each)
- **Core Framework:** Python and LangGraph

## Work Completed

1. **AI Project Planning:** Defined the ShopEase project objectives, problem statement, scope, expected outcome and proposed technology stack.
2. **Requirements Analysis:** Identified functional and non-functional requirements for the customer support application.
3. **Architecture Review:** Reviewed the existing multi-agent workflow consisting of Coordinator, Research, Analyzer, Writer and Critic agents, along with the knowledge base and FastAPI backend.
4. **Sprint Planning:** Divided the planned improvements into four two-week sprints, covering project review, RAG integration, LLM and tool integration, testing and deployment preparation.
5. **Effort Estimation:** Classified individual project tasks as Low, Medium or High complexity.
6. **Task Prioritization:** Assigned priorities based on business value and dependencies between tasks.
7. **Team Workflow:** Defined proposed team responsibilities, task tracking, Git collaboration, code reviews and sprint reviews.
8. **Project Timeline:** Prepared an eight-week timeline with milestones and a final completion target at the end of Week 8.

## Sprint Breakdown

| Sprint | Weeks | Focus |
|---|---|---|
| Sprint 1 | 1–2 | Existing project review, requirements, architecture and development planning |
| Sprint 2 | 3–4 | RAG, embeddings, vector storage and semantic retrieval |
| Sprint 3 | 5–6 | LLM integration, response evaluation and basic order-status lookup |
| Sprint 4 | 7–8 | Testing, bug fixing, deployment preparation and documentation |

## Proposed Technology Stack

- **Programming Language:** Python
- **Agent Workflow:** LangGraph
- **Backend:** FastAPI
- **Knowledge Base:** JSON and structured support documents
- **RAG:** Embeddings and vector search
- **AI Integration:** External LLM API
- **Testing:** Pytest
- **Version Control:** Git and GitHub
- **Deployment:** Docker and cloud hosting provider
